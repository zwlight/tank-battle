# 坦克大战 🎮 Battle City

经典 **Battle City（坦克大战）** 风格的 HTML5 网页游戏，使用 Canvas 纯前端渲染，无需安装任何插件，打开浏览器即可游玩。

## 🕹️ 在线试玩

👉 **https://zwlight.github.io/tank-battle/**

## 🎯 游戏目标

控制你的金色坦克，保卫基地（鹰旗），消灭所有敌方坦克！

- 每击毁一辆敌方坦克 **+100 分**
- 保护基地不被摧毁，否则游戏结束
- 你有 **3 条生命**，被击中后会重生
- 消灭全部 **20 辆敌军坦克**即可获胜

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` | 移动坦克 |
| `Space` | 射击 |
| `Enter` | 开始 / 重新开始 |

## 🗺️ 地图元素

| 元素 | 说明 |
|------|------|
| 🧱 **砖墙** (棕色) | 可被子弹摧毁 |
| ⛓️ **钢墙** (灰色) | 不可摧毁 |
| 🏠 **基地** (金色鹰旗) | 必须保卫，被毁则失败 |

## 🤖 敌方 AI

- 敌方坦克会随机移动并主动射击
- 遇到墙壁会改变方向
- 会尝试向基地靠近
- 从地图上方 3 个出生点随机刷新

## 🛠️ 技术实现

- 纯 HTML5 + Canvas + JavaScript，单文件无依赖
- 像素级碰撞检测
- 粒子爆炸特效
- 响应式界面布局
- 网格化地图系统

## 🚀 本地运行

```bash
git clone https://github.com/zwlight/tank-battle.git
cd tank-battle
# 直接用浏览器打开 index.html 即可
```

或者用 Python / Node.js 启动本地服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`。
